# MUCLIVA Brand Refresh

Update the entire MUCLIVA Immobilien website to use the NEW official brand color palette from my latest uploaded reference image.

Official Brand Colors

Forest Green: #1B3D2E — Primary color

Sage: #8FAE95 — Secondary color

Champagne Gold: #D4B483 — Accent color

These exact HEX codes replace all previously specified MUCLIVA brand colors.

Important Rules

Maintain the premium, elegant German real estate aesthetic from the uploaded website screenshots.

Preserve the MUCLIVA name and official architectural M logo.

Update all pages, including Homepage, Verkaufen, Bewertung, Immobilien, Über uns, Kontakt, and Footer.

Update the global CSS variables and Tailwind design tokens rather than applying inconsistent individual overrides.

Ensure buttons, text, forms, cards, and navigation have accessible contrast.

Keep champagne gold subtle and sophisticated.

Do not use the previous colors #0F3D2E or #C9B37E.

Keep the overall design harmonious and consistent across desktop, tablet, and mobile.

Do not rebuild the website from scratch. Preserve the existing layout, content, components, and functionality. Only update the design system and colors to match the new official MUCLIVA palette.
